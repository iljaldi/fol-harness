# R2 · 목적

> 2026-10-03 확정

## 매번 바뀌는 것

**대상 화면 1개.** 한 번 실행할 때 PRD 5장의 화면 5개 중 하나를 입력으로 받는다.

| 입력값 | 화면 |
|---|---|
| login | 로그인 |
| projects | 내 프로젝트 |
| intake | 프로젝트 시작 / 자료 입력 |
| workspace | 프로젝트 작업 공간 |
| preview | 프로젝트 문서 미리보기 / 다운로드 |

기준 문서, 게이트, 도구는 매번 같다.

## 사용자

**나 혼자.** 하네스를 실행하고 G5 결과를 입력한다. 내부 관계자는 하네스 밖에서 Figma 링크로 시안을 보고, 컨펌 결과만 내가 기록한다.

## 완료 기준

대상 화면 1개의 최종 화면 디자인이 Figma '05 최종' 페이지에 있고, gates.json에서 G1~G6가 모두 PASS이며, G6 판정 스크립트로 확인한 rules.json 위반이 0건이다.
