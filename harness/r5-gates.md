## 사람 승인 지점: G5 1곳

나머지 5곳(G1~G4, G6)은 스크립트가 개수를 세서 판정한다.

## 통과 조건

### G1 · 반영 포인트 (s1, s2 JSON)
- 레퍼런스가 5개이고, 모두 uibowl 링크가 있다
- 반영 포인트가 3개 이상이다
- 출처 레퍼런스 id가 빈 포인트가 0개다

### G2 · 유저스토리·규칙 B (s2 JSON)
- 유저스토리 번호(1~6)와 연결되지 않은 포인트가 0개다
- ★ **규칙 B**: 금지어가 들어간 포인트가 0개다
  - 금지어: 보장, 검증완료, 합격 보장, 100% 성공, 자동 승인, 강제 반영
  - 예외: `example` 태그가 붙은 포인트
- MVP 제외 기능이 들어간 포인트가 0개다
  - 포트폴리오 장표, 프로토타입 자동, Figma 연동, 인터뷰 대행, 합격 예측, 채용 매칭, 멘토 연결, 공동 편집, 구독, 버전 복원

### G3 · 화면 설계 확정·규칙 A (s3 JSON)
- 필수 항목 4개(화면 목적, 구성 요소, 상태, 이동 흐름)가 모두 있다
- 반영 포인트나 유저스토리 번호와 연결되지 않은 구성 요소가 0개다
- ★ **규칙 A**: workspace 화면이면, preview에서 돌아오는 흐름(`backFromPreview`)이 `keepContent = true`, `keepChat = true`다
- 프로젝트 전환이 있으면, 전환 흐름(`onProjectSwitch`)이 `resetStep = true`, `keepLogin = true`다

### G4 · 키스크린 (s4 JSON)
- 프레임이 2~3개다
- 모든 프레임의 너비가 1440px이고, 높이가 900px 이상이다
- s3 구성 요소 중 프레임 레이어 이름에 없는 것이 0개다

### G5 · 관계자 컨펌 (사람)
- gates.json에 내가 직접 입력한다
  - `status`: approved 또는 rejected
  - `reason`, `returnTo`(S3 또는 S4), `figmaLink`, `date`
- `approved`일 때만 S5를 시작한다

### G6 · 가이드 위반 0건 (s5 JSON vs rules.json)
아래 항목이 모두 0개여야 한다.
- 토큰에 없는 색 Hex
- NotionInter·Inter가 아닌 폰트
- 타입 스케일에 없는 글자 크기 (12·14·15·16·20·22·24·26·28·32·40·54·64만 허용)
- 400·500·600·700이 아닌 굵기
- 허용값이 아닌 radius (0·4·5·8·12·16·9999만 허용)
- spacing 허용값이 아닌 간격 (0 포함, rules.json 참고)
- 터치 영역 44px 미만인 인터랙티브 요소 (button·icon·tab·menuItem)
